关键根因（三处，均为真机取证而非推断）：
1. **遮挡**来自 `client.cjs` 的降级分支 `.hwb-fallback{position:fixed;right:0}`——因为
   `ctx.get('betterSidebar')` 在 `ctx.inject` 异步就绪前求值恒为 undefined，导致「有官方 tab 的同时
   又挂了浮层」。迁移到官方 seat 后该分支连同代码一并删除。
2. **打开异常**来自站点脚本跨域：DeepSeek HTML 用绝对 URL + crossorigin 引 `fe-static.deepseek.com`，
   而该域返回 `Access-Control-Allow-Origin: https://*.deepseek.com`（字面量通配，非法值），浏览器硬拒，
   整页退化「页面资源加载异常」。修复后真实 Edge 渲染完整登录页、控制台 0 错误。
3. **顺序坑**：若先注入 bootstrap 再改写 URL，bootstrap 自身的 `UP`/`ASSETS` 常量会被一起改写，
   运行时比较永不命中——真机表现为 GLM 埋点仍被 CORS 拦（52 条）。已由 mirror.test.mjs 护栏锁住。

其余事实：官方右侧栏**没有**刷新入口（`reload/Retry` 0 次，`refresh()` 仅为内部方法），故自建刷新按钮；
Kimi 旧域名只剩 302 到 www.kimi.com；chatgpt/grok/gemini 在本机直连与走 127.0.0.1:7897 代理均不可达
（属环境网络限制，非桥缺陷）。
