# 2026-09-11 工具调用折叠（0.9.1）

[2026-09-11] 网页面板工具调用代码块折叠 | 新增 lib/toolfold.js（注入纯前端折叠脚本：
按 mcp_action/tool_call 判定，纯字符串扫描避开正则转义；把工具协议 <pre> 换成一行
摘要 header，点击展开；不改站点 DOM 结构，MutationObserver 跟随流式渲染）、
lib/mirror.js（import 并在 bootstrap 之后注入）、test/toolfold.test.mjs（真机 Edge 护栏：
折叠计数/摘要文案/状态标签/普通代码块不受影响/点击展开） | 版本 0.9.0→0.9.1；单测 55/55 绿。

起因：用户反馈「只要调用工具就会回复一堆代码，混杂在答案与上下文里非常不好阅读」。

实现选择与理由：
- **在镜像层注入，而非改桥的解析**。工具协议块的原始文本必须照旧传给 Harness
  （parseAgentReply 要读它），折叠只是「显示层」的事，动解析会伤到工具闭环。
- **判定用字符串扫描而非正则**。上一轮已踩过「正则写在模板字符串里被转义吃掉」的坑
  （mirror.js 的 toLocal），这里一律 indexOf/slice。
- **不改站点 DOM 结构**，只 insertBefore 一个 header 并切换原 <pre> 的 display：
  站点是 React 应用，改结构容易与它的协调算法冲突。
- **独立成 lib/toolfold.js**，用模板字符串承载：先前把这段塞进 mirror.js 的
  字符串数组里，多层引号转义直接产出语法错误的注入脚本（pageerror:
  missing ) after argument list），真机验证才暴露。

实测（真机 Edge）：4 个块中 3 个工具块折叠、普通代码块保留；摘要为
「⚙ pwsh | command: Get-ChildItem -Force」「✓ pwsh | success」；点击后首个块展开、
其余保持折叠。
