# 0.4.1 安全与逻辑审查

人工源码审查、实际命令和回归测试；不沿用旧文档无证据的“全部安全”或独立代理结论。

## 已处理

- 移除 token 导出接口和剥离 CSP 的站点反向代理；旧镜像路径返回 410。
- 同源控制接口检查 loopback Host、Sec-Fetch-Site 与精确 Origin/白名单；跨站和伪造 Host 已用测试验证拒绝。
- 预览仅回截图；交互仅允许限定坐标、文本、键盘和滚动，拒绝任意 JS。生成中拒绝人工操作，工具执行仍归 Harness 权限系统。
- 移除提示词、工具输出正文日志；诊断仅记录模型/思考/搜索参数，不记录凭据。
- 工具参数采用 JSON.parse，已知工具名白名单；普通 JSON 示例不执行。对实际 DeepSeek Calling 形式要求明确标记与完整 JSON。
- 取消/超时先终止旧 executor，等待结算后释放队列；移除请求 abort 监听；有界队列、响应流大小限制。
- 上下文 SHA256 检查历史改写和模型切换；失败不提交游标；首轮完整历史序列化由重复扫描优化为线性扫描。
- webServer 路由 disposer 收集卸载，防止热重载残留。

## 仍需注意

- 同机进程及可信 Harness 插件能够访问本地控制接口；没有跨操作系统用户隔离或远程访问认证，不应暴露端口到公网。
- 网页模型不是可信执行器，工具标记可能出现在示例或提示注入里；Harness 原生权限与审批不能关闭。
- 上下文和工具结果会发送至 DeepSeek 网页，截图也含会话内容。只将允许发送的项目用于该 provider。
- 图片附件上传、网页导入 API、同会话并发调用、手动网页编辑后自动上下文重建仍未完整验证。
- 工具结果有 16000 字符截断且附提示；大文件审查应分段读取。
- token 和 TPS 是估算，非官方 tokenizer 或计费统计；极短整帧回复的原生流速仍可能不稳定。
- 自动化与站点内部协议可能随改版、限流和账户状态改变，未知模型必须报错。
